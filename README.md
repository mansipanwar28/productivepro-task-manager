# ProductivePro

ProductivePro is a modern task management web application designed to help users organize daily tasks efficiently.

## Features
- Add and delete tasks
- Mark tasks as completed
- Filter tasks
- Task statistics
- Responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript
- Font Awesome

## Future Improvements
- Local Storage
- Dark Mode
- Task Priorities
- Authentication
